# Erreurs connues

Registre des erreurs déjà rencontrées sur ce projet, pour ne jamais les refaire ni les rediagnostiquer. Claude le lit avant tout débogage et y ajoute une ligne **dès qu'une erreur est corrigée**, dans le même commit que le correctif.

Règles d'écriture :

- Une ligne par erreur, la plus récente en haut.
- Le symptôme tel qu'on le voit (message exact, comportement), pour qu'une recherche le retrouve.
- La cause en une phrase, puis le correctif ou la règle à suivre.
- Une erreur qui peut toucher d'autres projets remonte aussi dans [lecons-projets.md](lecons-projets.md) (dans Best-README-Template).
- Ne jamais y copier un secret, un mot de passe ou un identifiant.
